# 开局界面设计方案：MINGAN-OS 像素风 Windows 桌面启动器

> 基于 \*\*UI/UX Pro Max (`Pixel Art + Hero-Centric Retro Desktop`)\*\* 设计方法论与当前《黑域协议：替壳者》 \*\*Pixel Cyber OS\*\* 视觉规范制定。

\---

## 1\. 设计目标与叙事契机

将游戏开局的第一屏从“直接进入牌桌”前置为**现实世界中的一台像素风 Windows 黑客终端桌面**：

* 玩家开局面对自己凌乱的现实电脑桌面，代表此时尚未接入黑域（或快捷方式刚被强制清理）。
* 玩家在桌面上探索时，会发现 **「回收站」** 中躺着此前被删除的 **「黑域协议网.lnk」** 快捷方式；打开回收站并启动（或双击/还原接入）该快捷方式，即完成了「从现实终端主动潜入黑域」的开局仪式，顺滑接入 `SEC-00` 新手教学或当前逃亡进度。

\---

## 2\. UI/UX Pro Max 规范与风格融合

### 2.1 视觉系统对齐（Pixel Cyber OS）

完全沿用 [pixelCyberOs.css](file:///G:/DS/DSH/Project-DSH/ST/mingan-holdem/src/styles/pixelCyberOs.css) 既有 Token 与工艺约束：

* **色彩体系**：

  * 桌面底板：`#05070c` 搭配微弱青色像素点阵网格（`16px` 格线），比局内 `#000000` 多一层现实 OS 桌面壁纸纹理，中央嵌入低对比度像素水印 `MINGAN-OS 98 // NODE: RL-TERMINAL`。
  * 窗口与任务栏材质：`--bg-panel (#0b0d14)` 与 `--bg-surface (#07080c)` 配合 Windows 95/98 经典双层内嵌像素立体斜边（浅灰青高光 `inset 1px 1px 0 #566382` + 深黑投影 `inset -1px -1px 0 #020306`），保留严格直角 `border-radius: 0`。
  * 功能语义色：`--neon-cyan (#00f0ff)` 主焦点、`--neon-emerald (#10f5a0)` 「维心」聊天气泡图标、`--neon-pink (#ff2e88)` 黑域受损快捷方式、`--neon-amber (#ffb020)` 文件夹与警告徽标、`--neon-danger (#ff4757)` 关闭与粉碎态标签。
* **字体与像素质感**：`DotGothic16 / Silkscreen / JetBrains Mono`，数字时钟强制 `font-variant-numeric: tabular-nums` 防止每秒/每分钟跳动导致布局偏移；微弱 RGB 色散重影 `--px-ghost-ui`。
* **图标与质量门禁**：全部采用 16x16 / 24x24 `crispEdges` SVG 像素图标，**零 Emoji、零 `window.alert/confirm`、全部交互控件带唯一 `id`**。

### 2.2 可用性与无障碍要点（UI/UX Pro Max Checklist）

* **交互容错**：桌面图标与回收站内的「黑域协议网」同时支持 **鼠标双击启动** 与 **单击选中 + 底部主按钮 / 浮动操作提示（或回车键）启动**，避免触控屏或习惯单击的网页玩家不知道需要双击而卡关。
* **对比度与焦点**：文本对背景对比度严格 >= 4.5:1；全部图标、菜单、关闭按钮支持 `Tab` 键顺序聚焦、`Esc` 键关闭开始菜单/回收站窗口、`prefers-reduced-motion` 下关闭脉冲闪烁。
* **响应式适配**：桌面端（1024px–1440px+）展现完整分散凌乱桌面布局；窄屏/移动端（<= 768px）自动切换为自适应网格流排布，弹窗与开始菜单安全收容在任务栏上方。

## 3\. 桌面布局与核心元素清单

### 3.1 桌面图标区（Desktop Canvas）

#### A. 核心可交互图标

1. **回收站（`desktop-icon-recycle`）**

   * 位置：桌面左上角醒目主位（附带柔和青色轮廓提示与“内含项目”满桶像素图标造型）。
   * 行为：点击选中，双击或点击图标下方操作/再次回车打开\*\*「回收站」像素窗口\*\*。
2. **维心（`desktop-icon-wexin`）**

   * 造型：neta 微信，使用 `--neon-emerald (#10f5a0)` 双重叠像素对话气泡 SVG 图标，名称标注 `维心`。
   * 行为：目前暂无实际作用。点击时仅可选中；若双击触发，仅弹出轻量桌面内系统气泡/只读小提示（例如：`\[维心] 本地客户端未挂载通讯证书，当前暂无消息可用`），不阻塞桌面操作。

#### B. 摆放凌乱的装饰性文件与文件夹（纯装饰，暂无实际作用）

为了营造黑客主角刚被断网或仓促整理过的工作台氛围，在桌面上放置约 8–10 个坐标略显凌乱的文件与文件夹（保持最小触控间距避免遮挡回收站和维心，点击仅做视觉选中框高亮，暂无实际功能）：

* **文件夹类**（琥珀/暗蓝像素文件夹图标）：

  * `新建文件夹 (3)`（偏移放在右侧偏上）
  * `工作目录\_勿删`（中偏右）
  * `临时转储\_0x4F`（左中略微错格）
  * `旧版备份\_2025`（右中）
* **文档 / 截图 / 杂项文件类**（记事本 / 损坏文本 / 图片像素图标）：

  * `未命名截图\_final\_v2.png`
  * `房租水电催缴.pdf`
  * `系统日志\_crash.txt`
  * `仇恨之书.txt`（标题：别碰黑域网，内容详细记载了玩家第一次进入黑域网后被算力猎手暴打的经历）
  * `桌面清理待办.note`

> \*\*视觉排版细节\*\*：左列上方放 `回收站` 与 `维心`，右侧、下侧及中区留白处采用非对称离散网格坐标摆出上述文件夹与文件，既有真实 Windows 杂乱感，又能保证核心交互图标第一时间被玩家看见。

### 3.2 回收站窗口（Recycle Bin Explorer Window）

打开「回收站」后在桌面居中弹出像素风 Windows 资源管理器窗口（`id="desktop-window-recycle"`）：

* **标题栏**：`\[像素回收站图标] 回收站 // MINGAN EXPLORER`，右侧配置复古方形 `\_`（仅视觉/最小化）与 `X` 关闭按钮（`#recycle-btn-close`）。
* **地址与状态栏**：`路径: Desktop\\回收站` ｜ `项目数: 3 (含 1 个可执行残留快捷方式)`。
* **回收站文件列表**：

  1. **黑域协议网.lnk**（主聚焦项，带品红损坏快捷箭头叠加 `NetrunnerBrandLogo`）：

     * 原位置：`C:\\Terminal\\Desktop`
     * 状态：`已被上行节点强制移除 · 可应急还原并直连`
     * 操作：双击该条目，或点击选中后按下窗口底部高亮主按钮 **「还原并接入黑域协议网」(`#recycle-btn-launch-mingan`)**，立即触发黑域接入！
  2. **2 个已彻底粉碎的装饰残留项**（灰色不可执行，`status: 已粉碎 \[0x00]`）：

     * `blackriver\_handshake.tmp`
     * `node\_key\_expired.bak`
* **底部操作栏**：

  * 主按钮（霓虹青发光）：`#recycle-btn-launch-mingan` -> 文案随存档适配：初次游玩显示 `还原并启动「黑域协议网」`，已有进度则显示 `重新接入「黑域协议网」`（附进度提示如 `当前节点: SEC-02` 或 `自由模式`）。
  * 次按钮：`清空提示 / 关闭窗口`。

### 3.3 底部任务栏（Taskbar，固定高 42px）

横跨画面最底部，采用深空蓝黑像素底板 + 顶部 2px 亮边框：

1. **左下角 · 「开始」按钮 (`#desktop-btn-start`)**：

   * 图标：像素风 Windows 四色窗格徽标（呼应游戏 `#00f0ff / #ff2e88 / #ffb020 / #10f5a0` 四色）。
   * 文字：`开始`。点击切换弹出/收起开始菜单，弹出时按钮保持内凹激活高亮态。
2. **中间 · 窗口任务标签区**：

   * 回收站打开时显示任务栏按钮 `回收站`，点击可聚焦或收起回收站；未开窗口时显示极简状态指示 `LOCAL\_RL // STANDBY`。
3. **右下角 · 系统托盘 + 实时系统时间 (`#desktop-taskbar-clock`)**：

   * **托盘微按钮**：音效静音切换快捷按钮（`#desktop-tray-sound-btn`），同步 `soundSettings`。
   * **系统时间显示**：每秒/实时更新本机时间，两行或紧凑单块复古排版（第一行 `HH:MM`，第二行 `YYYY/MM/DD`，hover title 含完整时间与秒数）。

### 3.4 弹出式「开始」菜单（Start Menu — 设置相关功能）

点击左下「开始」向上弹出双栏复古像素菜单（`#desktop-start-menu`）：

* **左侧竖排装饰条**：深青黑垂直标题条 `MINGAN OS 98`（竖排像素字）。
* **右侧功能清单**（全部聚焦**设置与系统功能**，直接对接游戏已有配置面板，不与开始游戏主路径抢焦）：

  1. **音量与音效设置**（`#start-menu-sound`）：菜单内直接提供静音开关 + 音量百分比滑块，无需二级弹窗即可调节。
  2. **LLM 网关配置**（`#start-menu-llm`）：打开现有 `'llm'` 弹窗（配置 OpenAI 兼容 / Google Vertex AI 接口）。
  3. **预设与世界书管理**（`#start-menu-preset-wb`）：打开现有 `'preset-wb'` 弹窗（编辑 SilyTavern 预设与世界书）。
  4. **对局数值调优**（`#start-menu-tuning`）：打开现有 `'tuning'` 弹窗（筹码规模、换牌费用、AI 难度与风格）。
  5. **规则与牌型手册**（`#start-menu-rules`）：打开现有 `'protocol'` 弹窗（查看双花色大小阶梯与技能池）。
  6. **好友联机 (P2P)**（`#start-menu-p2p`）：打开现有 `'p2p'` 弹窗（允许在电脑桌面直接起联机房）。
  7. **调试控制台 (CMD)**（`#start-menu-cmd`）：打开现有 `'cmd'` 弹窗。
  8. **底部分割线 · 快捷操作**：

     * `进入逃亡路线图`（`#start-menu-escape-map`，仅在已有推进记录或方便测试跳转时直达路线图）
     * `重置本地存档进度`（`#start-menu-reset-save`，弹确认后清空进度并留在桌面重新开始）。

## 4\. 启动流程与状态衔接架构

### 4.1 视图状态机扩展（`viewMode`）

将 [App.tsx](file:///G:/DS/DSH/Project-DSH/ST/mingan-holdem/src/App.tsx) 的 `viewMode` 扩展为：

```ts
type AppViewMode = 'desktop' | 'arena' | 'escape-map';
```

* **开局初始值**：默认从 `'desktop'` 启动（首屏即是像素 Windows 电脑桌面）。
* **VN / 教学触发时机调整**：

  * 当 `viewMode === 'desktop'` 时，不主动渲染局内对话/教程遮罩，而是把目标 `SEC-00` 引导或对应章节的开场 VN 保持为待触发状态；
  * 当玩家打开「回收站」并激活「黑域协议网.lnk」时，播放约 `520ms` 的干净终端连接转场（尊重 `prefers-reduced-motion`），然后切换 `viewMode` 至 `'arena'`（或若已完成 `SEC-00` 且在选关态则进入对应节点，并正常触发该节点的入场 VN / 桌面入场动效）。
* **回到桌面入口**：

  * 在游戏内设置菜单中补充「最小化 / 返回电脑桌面」按钮，允许玩家随时切回桌面调整设置或查看彩蛋。
