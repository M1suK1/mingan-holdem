# SEC-01 战败后视觉小说剧情脚本（供审查）

> \*\*设计定位\*\*：玩家在 `SEC-01 底层排水巷道` 将 \*\*凌翡（JADE-01）\*\* 算力清零后、进入战利品/逃亡路线推进前自动触发。  
> \*\*演出方式\*\*：沿用 `SEC-01` 开场左右双立绘均分舞台（左侧 `echo0` 玩家视角镜像，右侧 `sec01` 凌翡实体，第 12 句剥离后右侧切换为空壳暗化/退场效果）+ 底部居中对话框（保留虚线内心独白框、`\[ALARM]`/`\[EXTRACT]` 顶部状态提示与音效）。

## 三、衔接与表现确认点（供审阅）

1. **右侧空壳与抛弃演出（第 12–20 句）**：

   * 凌翡意识被剥离后（第 12–14 句），右侧立绘采用**极暗静态空壳**（配 `无主空壳投影 // JADE-01` 标签）；第 15–17 句玩家端详时点亮做预览，第 19–20 句玩家吓得抛弃后直接让右侧立绘退场，视觉上最直观。
2. **与现有战后奖励流程的衔接**：

   * `SEC-01` 战后原本会弹出技能战利品弹窗（选择 `算力虹吸` 或 `超频诈唬`）并解锁前往 `SEC-02 中继审计网关`。
   * 建议触发顺序：**击败凌翡后先播这段 20 句战后剧情 -> 结束再弹出技能抽选/前往 `SEC-02` 逃亡地图**（表示玩家只来得及顺手扒了模块碎片就撒腿跑了，壳子没敢穿），或者你更想先选完技能再播这段？先弹剧情，再弹技能。
3. **绝对无剧透检查**：

   * 全段只围绕凌翡财阀身份与玩家保命逃亡展开，不涉及任何关于 `ECHO-0` 真名、叛逃黑盒或猎杀榜第一的信息。
