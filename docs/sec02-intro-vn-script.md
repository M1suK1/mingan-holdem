# SEC-02 开场视觉小说剧情脚本（修订版 · 供审查）

> **设计定位**：玩家仓皇逃离 `SEC-01` 并钻入 `SEC-02 中继审计网关` 后、正式开打 `SEC-02` 牌局前自动触发。  
> **演出方式**：左右双立绘均分舞台（左侧 `echo0` 玩家视角镜像，右侧 `sec02` **芙兰 // MUTE-02**）+ 底部居中对话框。  
> **设定与文本规范**：
> 1. **玩家背景设定**：玩家对黑域协议网仅粗浅了解规则；最初是受同事**林龙心**（「粉红软软龙」）推荐才加入，不料第一次上线就撞上「算力猎手」并惨败，从此留下心理阴影并弃坑了很长一段时间。直到最近重新花钱注册了一具新虚拟实体回归，才卷入序章以来的连环逃亡。因此面对芙兰时，玩家内心是**恐惧与旧日阴影翻涌**，但在走投无路下只能逼自己狠下心克服心魔。
> 2. **玩家代号占位**：脚本中所有原先指代玩家本人的旁白「你」，统一改为玩家代号占位符 `{codename}`（后续由开局自定义代号系统动态注入，默认可兜底如 `PLAYER`）。玩家台词中用于指代对面芙兰的「你」保持不变。
> 3. **芙兰表现约束**：芙兰全程**不使用虚线心理独白框（无 `isThought`）**，所有发言全部为 `[VOCAL_ERR]` 乱码，仅通过**表情差异切换**与肢体小动作和玩家互动。
> 4. **禁用粗口自称**：全程不使用「老子」等违和粗口。
> 5. **数值衔接定案**：进入 `SEC-02` 牌局后**保持双方初始 `750` 算力不变**，直接由第一手开局自动触发的「富兰克林之死」来呼应本次偷袭封锁效果。
