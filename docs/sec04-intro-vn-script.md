# SEC-04 开场视觉小说剧情脚本（修订版 · 供审查）

> **设计定位**：玩家摆脱 `SEC-03` 后沿黑暗隧道一路逃抵 `SEC-04 零号离线闸门`，即将从尽头的现实出口脱离黑域前、正式进入最终对局前自动触发。  
> **演出方式**：左右双立绘均分舞台（左侧 `echo0` 玩家视角，右侧 `sec04` **绯凪·千夜 // KIRI-04**）+ 底部居中对话框；`ECHO-0` 开口时从玩家立绘上**向左侧分出压暗虚影分身**（`split-out` → `split-hold`，采用 `err1` / `err2` 错误立绘并与玩家立绘保持交叠）。  
> **设定与文本规范**：
> 1. **玩家状态承接**：承接 `SEC-02` 左臂被「富兰克林之死」劈出的伤痕与 `SEC-03` 剧痛反噬后的头痛欲裂，开场呈负伤、难以集中精神、视野模糊且几乎放弃的濒溃态。
> 2. **低共情 AI 播报风的 `ECHO-0`**：因此前逃亡几乎耗尽共情能力，此刻她的残余共情虽被玩家濒死绝望重新触发，开口发言却依然近乎**毫无感情波澜的 AI 系统播报**——冷静播报生物电信号阈值、消耗剩余共情屏蔽痛觉与视觉噪点，并客观给出「建议继续前进」的指示。
> 3. **玩家代号占位与用词**：旁白与系统提示统一使用 `{codename}`，旁白零「你」，正文零分号（`；`/`;`），零「老子」。

## 三、衔接与演出确认点（供审阅）

1. **`ECHO-0` 低共情 AI 播报风还原**：
   - 第 12、14 句彻底移除柔声安慰与 `smile` 表情，改为平直、客观、接近无感情 AI 系统日志播报的句式（「生物电信号跌破存活临界值」「痛觉屏蔽率 100%」「最优解建议：保持前进，不要在此停滞」），同时与「再次消耗残余共情救人」的行为本身形成外冷内微光的反差。
   - 第 15 句玩家反应同步改写，吐槽她连救人时口气都跟机器播报日志一模一样，与 `SEC-03` 结尾的压迫感无缝衔接。
2. **玩家左外侧压暗虚影（`auxLeftSprite`）**：
   - 第 12–14 句使用既有的 `auxLeftSprite` 槽位在玩家左侧（`echo0` 主体左外侧）放置 `echo0/err1` 与 `echo0/err2` 并设置 `visibility: 'dimmed'`（压暗效果），直观演出「`ECHO-0` 残余意识虚影在玩家耳侧低语播报」。
3. **规则自检**：
   - 全文旁白均使用 `{codename}` 占位，旁白零「你」，正文零分号（`；`/`;`），零「老子」。请审阅本修订稿，确认无误后我将立即写入 `SEC-04` 剧情模块、头像支持与测试！
