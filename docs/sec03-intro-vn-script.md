# SEC-03 开场视觉小说剧情脚本

> **设计定位**：玩家刚从 `SEC-02 中继审计网关` 的红色清洗警报下仓皇逃离、撞入 `SEC-03 黑市频谱暗道` 后，在正式进入 `SEC-03` 牌局前自动触发。  
> **演出方式**：左右双立绘均分舞台（左侧 `echo0` 玩家视角镜像，右侧 `sec03` **粉红软软龙 // NEON-03**）+ 底部居中对话框。  
> **设定与文本规范**：
> 1. **身份与脸盲喜剧反差**：玩家逃亡途中慌不择路与「粉红软软龙」撞了个满怀，回过神时隐约觉得对方的声音、粉青配色的脱线气息和工牌气质有点熟悉（实为现实中推荐玩家入网的「霓虹心」同事林龙心），却没来得及深想就被严重脸盲的她当成全网热传的强敌「零小姐」强行拉着手连入牌局。
> 2. **玩家代号占位**：旁白与状态文本统一使用 `{codename}` 占位，旁白零「你」，无「老子」、无分号（`；`/`;`），不提前泄露 `ECHO-0` 真相剧透。
