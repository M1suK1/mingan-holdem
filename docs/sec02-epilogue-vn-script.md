# SEC-02 击败芙兰后视觉小说剧情脚本（供审查）

> \*\*设计定位\*\*：玩家在 `SEC-02 中继审计网关` 将 \*\*芙兰（MUTE-02）\*\* 算力清零后、进入战后技能战利品弹窗与继续逃往 `SEC-03` 前自动触发。  
> \*\*演出方式\*\*：沿用左右双立绘均分舞台（左侧 `echo0` 玩家视角镜像，右侧 `sec02` 芙兰实体；第 09–11 句切换为暗化空壳与粒子消散退场效果，最终完全抹除隐藏）+ 底部居中对话框。  
> \*\*设定与文本规范\*\*：
> 1. \*\*玩家代号占位\*\*：旁白与状态文本中统一使用 `{codename}` 指代玩家，绝不在旁白中直接使用「你」，后续由渲染层按玩家设定代号自动替换。
> 2. \*\*芙兰表现约束\*\*：芙兰全程\*\*不使用虚线心理独白框（无 `isThought`）\*\*，所有发声继续表现为 `\[VOCAL\_ERR]` 乱码，仅靠 `surprise` / `angry` / `sad` 表情变化与震颤动作传达崩溃与绝望。
> 3. \*\*禁用符号与措辞\*\*：台词与旁白正文不使用中文或英文分号（`；` / `;`），不使用「老子」等违和自称，不泄露 `ECHO-0` 真实身份剧透。

## 三、衔接与演出确认点（供审阅）

1. **右侧强制登出与永久删除演出（第 06–11 句）**：

   * 芙兰从 `surprise`（惊愕）切到 `angry`（本能反抗），黑河指令介入后转入仓库里尚未在开场用到的 `sad`（含泪发抖），随后切换为 `shell-dim`（暗化停机态）并触发 `dissipating`（消散抹除动画），第 11 句完全 `hidden` 退场。全程不使用 `isThought` 心理框，仅靠表情与 `\[VOCAL\_ERR]` 乱码完成情绪落差。
2. **与战后技能获取及 `SEC-03` 衔接**：

   * 击败芙兰后先播放这 18 句战后剧情，第 17 句自然衔接「无法夺取虚拟实体，但顺手捞走底层技能模块」，随后弹出 `SEC-02` 战后技能奖励弹窗（选择 `富兰克林之死` 或 `ICE防火墙`）并开放前往 `SEC-03 黑市频谱暗道`。
3. **规则自检**：

   * 全文零分号（`；`/`;`）、旁白零「你」（全用 `{codename}` 占位）、零「老子」、零 `ECHO-0` 剧透。请审阅这份剧情文件，确认没问题后我再写入代码并接入通关流程！
